# Extendesk web

Sitio estático (sin build) para `extendesk.app`: portada (`index.html`) y política de privacidad (`privacy.html`).

Despliegue en Vercel: importar el repositorio con **Root Directory = `web`** y sin framework; cada push a `main` publica.

Pendiente: enlaces de descarga reales (Play y instalador de Windows), `app-ads.txt` cuando exista la cuenta de AdMob,
y versión en español.
